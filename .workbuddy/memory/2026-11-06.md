## 报名页改版：TechArena RU/EN 双语站（用户重写了 demo/public/index.html，805KB）

新需求：存储 username（同意书里的姓名）、residential address、ip（明文）、注册时间；「姓名+地址」都相同才判重复。

改动：

- `demo/public/index.html`：consent-ok 点击时 POST /api/register；201 → 存 localStorage 并解锁表单；409 → 双语提示「已存在」1.6 秒后仍解锁（因为同意书已记录过、邮件地址本身公开；如需严格模式再改）。后台入口（admin-link/admin-foot）改为弹窗输入 ADMIN_TOKEN 后打开 /api/users?token=。
- `demo/server.js`、`worker/test.mjs` 同步新契约（mock 用 JS toLowerCase 的 pair key，与 dup_key 语义一致）。

验证：单测 16/16；wrangler dev 实测西里尔大小写变体 409、同地址不同名 201、列表含 ip/created_at。

环境坑：`(npm run dev &)` 后台方式这次会被会话结束杀掉，要用 run_in_background=true 的受管后台任务；curl 本地要加 `--noproxy '*'`（代理环境变量会干扰）。

## 排查「弹出逻辑在浏览器里不生效」

- 实测结论：代码本身没问题。用无头 Edge（`--headless=new --remote-debugging-port`，CDP + Node 原生 WebSocket）加载真实页面，10 条断言全 PASS：首访弹出、点取消写入 `ta-consent-dismissed-v1`、刷新不再弹、`?consent=force` 强制弹出并清标记、有 `ta-consent-v3` 时不弹且解锁。
- 用户看到的「不生效」最可能是**本地已有记录**：`ta-consent-v3`（之前测试提交过同意）或 `ta-consent-dismissed-v1`（点过一次 Cancel）→ 按规则就不再自动弹。
- 顺手加固 `demo/public/index.html`：①自动弹出不再挂在 `load` 上（外链字体慢/被墙时 load 会延迟几十秒），改为 DOMContentLoaded + 120ms，`load` 仅兜底；②支持 `?consent=force` 清两条记录并强制弹出，方便自查；③跳过时 `console.info('[consent] auto-open skipped —', {...})` 直接说明原因。
- 环境备忘：本机有 `C:/Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，可直接用 CDP 做真实浏览器验证；注意 `run_in_background` 里直接启动 msedge 会 367ms 退出（进程分离），要在同一条命令里 `msedge ... & sleep 600` 才能常驻。
